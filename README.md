# Bowie Space Dog

Static landing page and article page for the Bowie Space Dog website.

## Files

- `index.html` - homepage entry file for hosting.
- `spcx-space-dog-landing.html` - original homepage filename.
- `bowie-story.html` - article page.
- `assets/` - website image assets.

Open `index.html` in a browser to preview the site locally.
